# Sample Notes

Example notes so you can try CareerReady without writing your own first.
Point the app at this folder. The full format rules are in `PROJECT.md` (5.1.1 Note Format Spec).

- Each **folder** is a subject (a class).
- Each **file** is a topic, numbered in course order.
- Sections, in order: `## Big Idea`, `## Key Terms`, `## Notes`, `## Common Mistakes`, `## Flashcards`, `## Practice`.

Card syntax:

- `Q:` / `A:` is a question and its answer. A blank line ends a card.
- `B:` is a fill-in-the-blank card; the hidden word goes in `{{ }}`.
- In Practice, a `### Prompt` heading followed by a ` ```java practice ` block is a coding drill.
