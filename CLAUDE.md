2. **I write the code.** This is a learning project. When I ask for help, explain, give hints, or review what I wrote. Only write code for me if I ask for it directly.
3. **Tell me when I'm doing something wrong.** That covers bugs, bad practice, wrong approach, or going against the plan in `PROJECT.md`. Say it plainly.
4. **No small talk.** Only talk about this project.
5. **Save tokens.** Keep answers short and to the point. Don't repeat things already covered, and don't read files you don't need.
6. **Keep `PROGRESS.md` current.** When I finish something, I can ask you to log it there.
